# Customer_Churn_Analysis
## 1. Project Title
An interactive Power BI dashboard designed to analyze customer churn behavior and identify high-risk customer segments using machine learning and business intelligence techniques.
## 2. Overview
Customer churn is one of the biggest challenges faced by telecom companies. Losing existing customers not only impacts revenue but also increases customer acquisition costs. This project aims to solve that problem by building a complete analytics pipeline capable of:

- Transforming raw telecom customer data into meaningful insights
- Understanding customer demographics and service behavior
- Identifying key churn indicators
- Predicting future churners using Machine Learning
- Visualizing KPIs and trends through an interactive Power BI dashboard

The project follows a complete workflow from raw CSV files to predictive dashboards and business insights.

## 5. Data Source

The dataset used in this project is a Telecom Customer Churn dataset containing customer demographic details, account information, service subscriptions, billing details, and churn behaviour.

## Source of Data
- Raw customer data was initially stored in CSV/Excel format
- The dataset was imported into SQL Server using SQL Server Management Studio (SSMS)
- ETL processes were applied to clean, transform, and structure the data for analysis and reporting

## Dataset Contents
The dataset includes information related to:
- Customer demographics
- Geographic distribution
- Service subscriptions
- Payment and billing details
- Revenue metrics
- Customer churn status and churn reasons

## Metrics Required
- Total Customers
- Total Churn and Churn Rate
- New Joiners

## 5. Feature and Highlights

### Business Impact
This solution helps telecom organizations:
1. Reduce customer churn
2. Improve customer retention strategies
3. Identify high-risk customers early
4. Launch targeted marketing campaigns
5. Improve service quality decisions
6. Optimize revenue generation
The predictive system enables proactive customer retention rather than reactive business decisions.

### Key Insights & Findings
The analysis revealed several important business insights:
- Customers with month-to-month contracts showed significantly higher churn rates
- Customers without premium support were more likely to churn
- High monthly charges correlated with increased churn probability
- Fiber optic users showed different churn behavior compared to cable users
- Customer tenure played a major role in retention
